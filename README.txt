MEEYAM HEALTH FOUNDATION - LOGO FILES
=====================================

Based on the founders' seal design (two people joining hands under a care cross),
redrawn as clean vector artwork.

Folders
  full-colour/   Main logo. Use on white or very light backgrounds.
  reversed/      For dark purple backgrounds (website header, banners, slides).
  one-colour/    All purple. For rubber stamps, embroidery, single-colour printing.
  black/         For photocopies, newspapers, black-and-white documents.
  white/         All-white logo for photos and coloured backgrounds.

Versions
  seal                Round bilingual seal. Certificates, letterhead, official documents, stamps.
  horizontal          Symbol + name side by side. Website header, emails, reports.
  stacked             Symbol above the name. Posters, standees, social media posts.
  MYHF-horizontal / MYHF-stacked   MYHF initials (MY = Meeyam, H = Health, F = Foundation)
                      with the full name below.
  *-tagline           Same logos with the tagline. Use only where the logo is large.
  icon                Symbol only. Small spaces, favicon, watermark.
  profile-picture     Round, ready for WhatsApp, Facebook, LinkedIn, Instagram.

Colours
  Meeyam Purple   #2C0A71   RGB 44 10 113    CMYK 61 91 0 56
  Care Green      #00BF63   RGB 0 191 99     CMYK 100 0 48 25
  Heart Red       #FF3131   RGB 255 49 49    CMYK 0 81 81 0
  White           #FFFFFF
  Red for small text on white     #E0282E
  Green for small text on white   #008A47
  Pantone: ask your printer to match these on a printed Pantone guide.
  Suggested starting points: Purple ~ Pantone 2685 C, Green ~ Pantone 7481 C, Red ~ Pantone Red 032 C.

Typeface
  Poppins (Bold 700, ExtraBold 800), free from Google Fonts. Includes Hindi (Devanagari).

Important for printers and designers
  The SVG files use the Poppins font for the name. Before sending to a print shop,
  open the file in a design tool with Poppins installed and convert the text to
  outlines/paths. The PNG files are finished images and can be used as they are.

Rules
  - Keep clear space around the logo equal to the height of one head.
  - Minimum size: seal 25 mm wide in print, icon 16 px on screen.
  - Do not stretch, rotate, recolour, add shadows or outlines.
  - The cross is white on green. Never make it a red cross on white (protected Red Cross emblem).
  - Show MYHF together with the full name, never on its own.
